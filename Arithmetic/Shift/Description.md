## Shift

* **Description**

    This design performs a bitwise right shift on an input value by two positions. It processes the incoming data and outputs the resulting value after the bitwise operation is complete.

* **Input Type**

    input_x: sc_uint<8>

* **Output Type**

    o_result: sc_uint<8>

* **Lines of Code (Dut)**

    41 lines

* **Source**

    Classical Algorithm
