## SimpleFSM1

* **Description**

    This design evaluates a sequential binary input to toggle between two states whenever a zero is detected, producing a high output only while in the reset state.

* **Input Type**

    input_x: bool

* **Output Type**

    o_result: bool

* **Lines of Code (Dut)**

    59 lines
