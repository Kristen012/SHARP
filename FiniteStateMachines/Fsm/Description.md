## Fsm

* **Description**

    This design detects the bit sequence 10011 in a continuous input stream. It outputs a match signal when the pattern is identified and supports persistent monitoring for overlapping or repeating sequences.

* **Input Type**

    input_x: bool

* **Output Type**

    o_result: bool
