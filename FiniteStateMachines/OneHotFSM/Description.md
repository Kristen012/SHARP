## OneHotFSM

* **Description**

    This design evaluates boolean logic equations using an input signal and one-hot encoded state bits to determine next-state transitions and two binary outputs for a ten-state system.

* **Input Type**

    input_x: bool & sc_uint<10>

* **Output Type**

    o_result: bool & sc_uint<10>
