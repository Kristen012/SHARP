## Q6C

* **Description**

    This design computes the next-state bits Y2 and Y4 for a six-state finite state machine by evaluating the present state vector and a binary input.

* **Input Type**

    input_x: sc_uint<6> & bool

* **Output Type**

    o_result: bool

* **Lines of Code (Dut)**

    54 lines
