## FindGCD

* **Description**

    This design calculates the greatest common divisor of two integers. It identifies the largest factor that divides both inputs evenly by checking values in descending order starting from the smaller number.

* **Input Type**

    input_x: sc_uint<8>

* **Output Type**

    o_result: sc_uint<8>

* **Lines of Code (Dut)**

    53 lines

* **Source**

    Classical Algorithm
