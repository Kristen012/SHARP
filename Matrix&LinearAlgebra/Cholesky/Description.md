## Cholesky

* **Description**

    This design performs Cholesky decomposition by factoring a symmetric matrix into a lower triangular matrix. It iteratively calculates each element through dot products and square roots to produce the resulting factorized output.
    
* **Input Type**

    input_x: fixed(8, 23)

* **Output Type**

    o_result: fixed(8, 23)

* **Lines of Code (Dut)**

    70 lines
