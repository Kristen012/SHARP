## Clustering

* **Description**

    This design performs K-means clustering by iteratively assigning data points to the nearest centroids and recalculating their positions. It organizes input coordinates into groups based on distance to find optimal cluster centers.
    
* **Input Type**

    input_x: sc_uint<16>

* **Output Type**

    o_result: sc_uint<16>
