## ArrayRotation

* **Description**

    This design performs array rotation by cyclically reordering elements based on a specified index. It shifts segments of the input data sequence to new positions to produce a rotated output.
    
* **Input Type**

    input_x: unsigned int

* **Output Type**

    o_result: unsigned int

* **Lines of Code (Dut)**

    64 lines

* **Source**

    Classical Algorithm
